# ArmKeyKey 0.10.0 · build 21（開發中）

- 繁簡、半形／全形快捷鍵可修改、清除或還原預設。
- 右上角提示加入 ArmKeyKey 圖示及通知式排列，沿用選字表樣式，包括自訂顏色、字體大小及縮放；不搶焦點，兩秒後收起。
- 聯想詞開關新增可自訂快捷鍵，預設為無；與聯想詞選詞修飾鍵分開。
- 設定頁可直接錄製組合，阻止重複使用同一組合；變更即時儲存至本機。
- 修正選單途徑的繁簡／全形切換沒有提示，並為聯想詞開關提供狀態提示。

只在 ArmKeyKey 輸入時生效。可用 Control／Command 配合英文字母、數字、標點或空白鍵，並可加 Shift／Option。以 ANSI 實體鍵位記錄；macOS 或 App 已佔用的組合可能無法生效。

維持 Apple Silicon、macOS 26.0 或以上。正式安裝後仍須登出再登入；首次安裝指引保留。目前未簽署、公證或發佈本版本。
