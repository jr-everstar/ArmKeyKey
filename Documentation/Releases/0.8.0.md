# ArmKeyKey 0.8.0（build 15）

新增 App 內軟件更新，支援 macOS 26 或以上嘅 Apple Silicon Mac。

- 設定頁及輸入法選單可手動檢查更新。
- 預設每日自動檢查，可關閉；通知需你授權，亦可略過指定版本提醒。
- 只提供適合目前 macOS／架構嘅版本，下載可取消。
- 安裝前驗證大小、SHA-256、Developer ID 簽署、公證及版本，再交由 macOS Installer。
- 輸入及學習資料仍留喺本機，更新檢查唔會上傳文字。

## 安裝及升級

0.7.2 或更舊版本需要先手動下載安裝一次。儲存工作並切換至其他輸入來源，關閉 ArmKeyKey，再執行 PKG。安裝需要管理員授權，完成後按 Installer 指示登出再登入。個人安裝需先按遷移指引移走舊 App，避免與共用安裝並存；學習資料會保留。
