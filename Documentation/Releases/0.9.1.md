# ArmKeyKey 0.9.1（build 18）

修正 App 內更新時已退出輸入法，卻因背景重新啟動而導致安裝失敗的問題。

- 安裝程式不再因偵測到 ArmKeyKey 程序而直接失敗，也不會強制殺掉輸入法。
- 共用安裝由 PackageKit 原子替換整個 App；安裝前備份至 `/Library/ArmKeyKey Installer Backup.*`。個人版維持原有備份遷移，學習資料及設定保留。
- 「準備安裝」失敗原因改用對話框顯示，不會藏在更新說明上方。
- 保留 0.9.0 的倉頡五代、傳統注音及智慧注音功能。

請先儲存工作並切換至其他輸入來源。安裝需要管理員授權，完成後所有使用者需登出再登入，才會完整切換到新版本。唔需要反覆喺活動監視器結束背景程序。

如 0.9.0 安裝失敗，請關閉舊 Installer 視窗，重新檢查更新並下載 0.9.1，或直接使用此版本 PKG；舊下載的 0.9.0 安裝包不會自動修正。
