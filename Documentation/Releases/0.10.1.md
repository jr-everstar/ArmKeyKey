# ArmKeyKey 0.10.1 · build 22

## Enhancements

- 改善 App 內更新流程：「準備安裝」確認後，自動切換至已啟用的鍵盤配置，再退出 ArmKeyKey 並開啟安裝程式，毋須自行找輸入來源切換快捷鍵。
- 確認視窗會說明將使用的鍵盤來源；優先採用最近使用的 ASCII 鍵盤配置。
- 取消時不切換。沒有合適來源或切換未成功時，停止準備安裝並顯示原因。

安裝仍需管理員授權；完成後所有使用者需要登出再登入，讓各 App 載入新版輸入法。設定及學習資料保留。適用於 Apple Silicon、macOS 26 或以上。

自動切換由 v0.10.1 的 App 提供。從舊版 App 升級至本版仍使用舊版更新流程，可能需要先手動切換輸入來源；安裝本版後，往後更新即可使用改善後的流程。
