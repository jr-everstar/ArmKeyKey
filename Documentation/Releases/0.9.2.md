# ArmKeyKey 0.9.2（build 20）

首次安裝後，唔使自己搵下一步；繁簡切換，亦即時睇到狀態。

## 安裝完成後，帶你加入輸入法

首次以 PKG 安裝並登出再登入，會自動開啟鍵盤設定及歡迎指引：

1. 「文字輸入」→「編輯⋯」→「＋」。
2. 「中文（繁體）」→「ArmKeyKey」→「加入」→「完成」。
3. 從螢幕右上角的輸入選單選擇 ArmKeyKey，開始打字。

指引每個帳戶只顯示一次，已啟用 ArmKeyKey 的帳戶及一般升級不會重複顯示。加入和選擇輸入來源仍由使用者決定；之後可從「安裝與使用」頁重新開啟鍵盤設定。build 19 測試包如未顯示指引，可直接升級 build 20 修復，毋須先移除。

## 快捷鍵切換提示

- `Control + Command + G`：切換繁／簡，右上角即時顯示目前狀態。
- `Shift + Command + Space`：切換半形／全形，使用相同提示。
- 提示毋須 macOS 通知權限，不搶輸入焦點，兩秒後收起；快速連續切換會顯示最新狀態。

保留原有六種輸入模式、設定及學習資料。適用於 Apple Silicon、macOS 26 或以上。安裝前請儲存工作並切換至其他輸入來源；需要管理員授權，完成後所有使用者請登出再登入。
