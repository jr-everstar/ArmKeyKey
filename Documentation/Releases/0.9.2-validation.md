## Post-publication shortcut feedback report — 2026-10-14

The user subsequently reported that Control+Command+G changes the output script but still shows no feedback. Investigation found that the input-method menu registers the same key equivalents, and its `toggleOutput:` action bypasses the notification call in `handleEvent:`. A new regression exercising direct and IMK-wrapped menu action senders fails on the published source with “menu shortcut emits exactly one matching notification”. This is a confirmed coverage gap in build 20; the earlier automated/raw-key and maintainer-confirmed acceptance records do not establish that menu-dispatched shortcuts displayed feedback. A working-tree fix moves feedback into the common output-toggle method and corrects stale notification-permission help. Published build 20 assets remain unchanged; real installed-input-method acceptance of this fix is pending.

After the fix, `Scripts/test-native.sh` passed (controller raw-key and menu dispatch, production feedback panel, first-login lifecycle), and `Scripts/build.sh` completed successfully. `git diff --check` passed. These results validate the local source fix, not the already published package.
