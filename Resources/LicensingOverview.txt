cj-ext.cin — 原始檔頭
# CangJie (often mis-Romanized as Changjei) input method table
# tweaked by b6s for OVIMGeneric(SQLite) in UTF-8 encoding.
#
# This table also extended to include HKSCS encodings. For details, see
#       http://www.info.gov.hk/digital21/chi/hkscs/index.html
#
# Now this table is supplied by CNS11643 to have around 70,000 Chinese
# characters. This work is based on opendesktop.org.tw's cj.cin file and
# merged by yylin and b6s.
#
