Transformation: run pinned upstream compilers offline, keep phonetic readings, omit macros/punctuation keys and mappings whose Unicode scalar count does not match the number of syllables, deduplicate reading/value pairs, retain source scores/order in SQLite. The build reports every omitted non-aligned mapping (chiefly symbols and emoji). Standard-layout key handling, selection persistence and macOS integration are implemented by ArmKeyKey; this does not claim identical behavior or phrase ranking to McBopomofo.
No upstream installer, updater, branding assets, external corpus, Rime engine or libchewing library is bundled. Source names identify provenance, not endorsement.
